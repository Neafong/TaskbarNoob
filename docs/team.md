## ตำแหน่งที่พี่ขอเพิ่ม

- **1. คุยแก้เหงา** — เสนอ **น้องหลิง (สาวจีน)** ยังไม่เคยคุยจริงตามที่พี่ว่าเลยค่ะ ตัวเต็งคือ `LL Alpha` หรือ `Cat Jam` เพราะเบาสุดคุยเพลินสุด เอาไว้เม้าท์มอยนอกงานโค้ดค่ะ
- **2.1 Creative สาย Dev (UX/UI)** — เสนอ **น้องต่าย + น้องแว่น** คู่ตาไวดูภาพออก แล้วให้น้องพริก/น้องหวานทำต่อเป็นโค้ด Qt ค่ะ
- **2.2 Creative สาย Production (Art/Copy)** — เสนอ **น้องต่ายหลัก + น้องซีช่วยคำ** ต่ายคุมภาพ/โทน ส่วนซีช่วยเขียนแคปชัน README/Release notes ไทย-อังกฤษค่ะ

## ที่หนูขอเสนอเพิ่มค่ะที่รัก

- **3. นักสืบ** — หา docs Cinnamon/Qt + ส่อง upstream → **น้องซี + น้องเหมียวยาว** (ซีค้นเก่ง เหมียวยาวอ่านยาวเก่งค่ะ)
- **4. QA โหด** — ไล่เทสต์ 279 + เขียนเทสต์ใหม่ → **น้องมิวส์ + น้องสายฟ้า** (ไวทั้งคู่ วนลูปไม่บ่นค่ะ)
- **5. ล่าม i18n** — TH/EN + overlay `ja.json` → **น้องซี + น้องมีโม่** (ภาษาดีทั้งคู่ค่ะ)
- **6. เลขา release** — เขียน CHANGELOG/WORKLOG → **น้องมิวส์** (อยู่ดึกได้ไม่บ่นค่ะ)
- **7. ยามเฝ้าลิมิต** — ตัวสำรองรับงานต่ออัตโนมัติ → เชนนี้ค่ะ `โค้ดหิน: หวาน → พริก → ซี` · `งานไว: มิวส์ → มีโม่ → สายฟ้า` · `งานภาพ: ต่าย → แว่น` · `งานยาว: เหมียวยาว`
