# ทีมพัฒนา TaskbarNoob

> อัปเดตล่าสุด: 2026-11-23 · หลักการทำงานร่วมกันระหว่างพี่นู๊บและเจนนี่ (ใน Antigravity)

## ทีมหลักปัจจุบัน (v0.2.0 → v0.3.0+)

| บทบาท | ชื่อ | หน้าที่หลัก |
|---|---|---|
| **เจ้าของโปรเจกต์ / ดีไซเนอร์** | **นู๊บ (Noob)** | กำหนดทิศทาง, ออกแบบ UX/UI & โลโก้, ทดสอบใช้งานจริงบน Linux Mint และ Windows 11 |
| **โปรแกรมเมอร์คู่ใจ** | **เจนนี่ (Jenny / Gemini)** | วางสถาปัตยกรรม, เขียนโค้ด & เทสต์, แก้บั๊ก, แพ็กเกจ และดูแลเอกสารทั้งฝั่ง Mint และ Windows |

## กติกาการทำงานร่วมกัน
- เริ่มงานชุดใหญ่ใน **เซคชันใหม่เสมอ** — อ่าน `AGENTS.md` + `docs/roadmap.md` + `docs/WORKLOG.md` ก่อนลงมือ
- รื้อโค้ดเป็นเฟสเล็ก (`R0 → R1 → R2 → R3 → R4`), รันชุดเทสต์ให้เขียว 100% และ commit แยกทุกเฟส
- ไม่เพิ่มฟีเจอร์/abstraction เกินจำเป็น — ยึดฟีเจอร์แกนให้แข็งแรง สะอาด และบำรุงรักษาง่าย

## บันทึกย้อนหลัง (ยุค v0.1.0 — OpenCode)
ในช่วงเริ่มต้นโปรเจกต์ (`v0.1.0`) พัฒนาร่วมกับทีมโมเดลใน OpenCode โดยมี **"น้องพริก" (Big Pickle)** เป็นผู้ช่วยหลักในการวางโครงสร้างแรกของฝั่ง Linux Mint ก่อนส่งไม้ต่อให้ **เจนนี่** รับช่วงต่อตั้งแต่ช่วงปิดงาน Windows `v0.2.0` และวางโครงสร้างใหม่ใน `v0.3.0` ค่ะ
